   Example: A renamed copy of a peer's program scores 1.00 against the 0.85 threshold, so the agent flags that pair. The instructor reviews flagged pairs rather than all 300 submissions.
   Benefit: Manual checking is narrowed to the suspicious cases, with the decision left to a person.
4. Coding-interview and hiring screens
   Example: A company runs 500 candidate solutions for a sorting task. The agent separates O(n log n) from O(n^2) solutions using operation counts and reports corner-case failures for each candidate.
   Benefit: Fast first-round filtering in which every rejection can be explained metric by metric.
Limits of this report:
1. Tests cannot prove correctness
   Example: submissions/examples/add_passes_but_wrong.c returns 0 only for the input 31337 271828. No test or generated case tries that input, so the agent reports 10/10 tests and full marks for a wrong program.
   Fix: Add property-based inputs and a larger seeded random budget, and treat a pass as evidence, not proof.
2. Sanitizers only see executed paths
   Example: submissions/examples/add_hidden_memory_bug.c overflows a heap block only when the first number is 31337. No input reaches it, so memory_safety reports no diagnostics and full marks, and the bug remains.
   Fix: Add Cppcheck-style static checks, widen the inputs, and never present a clean sanitizer run as proof of safety.
3. Complexity estimates cannot see inside library calls
   Example: A loop that calls strlen(text) in its condition is really O(n^2), but libc is not instrumented, so only the loop's own blocks are counted and the agent reports O(n). See tests/test_limitations.py.
   Fix: Combine with a timing curve or treat known linear libc calls in loops as a warning. Report the estimate as an estimate.
4. Similarity gives false positives on trivial problems
   Example: Two students independently write the shortest possible add.c. With so few tokens their normalized programs are identical, so the agent reports similarity 1.00 and raises a flag although neither copied.
   Fix: The report labels very short programs as low confidence, and a flag only ever asks for human review. Exclude starter code with template_file.
5. Similarity misses structural rewrites and unseen sources
   Example: An LLM-written solution that is absent from the corpus, or a copy reordered into differently shaped functions, scores low and is not flagged. The agent cannot search the internet or identify LLM authorship.
   Fix: Seed the corpus with solutions generated by common LLMs and public tutorials, and use viva questions to confirm ownership.
